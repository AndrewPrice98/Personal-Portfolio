Sudo-Snake

MED Featured: supporting Mobile game, iOS iPhone game (source not public)

Summary

Sudo-Snake is Snake rebuilt as a retro computer terminal: an offline iPhone arcade game with coils, bosses, a daily challenge and a 3D neon mode.

Problem

Snake, rebuilt as a retro computer terminal: an offline iPhone arcade game.

What I built

  • An iPhone arcade game in a terminal style.
  • Coils and bosses on top of the classic Snake loop.
  • A daily challenge.
  • A 3D neon mode, alongside terminal themes in green and amber.
  • Fully offline play.

How it works

The game is presented as a retro computer terminal, with green, amber and 3D neon themes, and it is playable offline.

The source for Sudo-Snake is not public, so this page describes the game and does not go deeper than its own description.
