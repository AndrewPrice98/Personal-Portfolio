CCNA Study

A full study platform for the CCNA 200-301 exam, built around a Cisco IOS simulator I wrote from scratch in JavaScript. 17 hands-on labs run right in the browser, with IOS modes, Tab completion and ? help, and simulate VLANs, trunks, Rapid PVST+, OSPF, HSRP, ACLs, NAT and DHCP snooping. Tasks grade themselves as you type. Also includes 225 original quiz questions, 196 flashcards, a subnetting trainer and per-chapter progress tracking.

CySA+ Study

An exam trainer for CompTIA CySA+ (CS0-004) with 16 performance-based labs. You investigate evidence in a Linux shell I built in pure JavaScript (pipes, grep, awk, sort, uniq, base64), flag malicious log lines, write firewall rules and order incident response steps, all with partial-credit grading. Includes a timed exam simulator, 400+ scenario questions with log and packet exhibits, a CVSS v3.1 calculator, and a validation script that proves every lab's solution scores 100%.

Job Tracker

A job-search organizer that reads your inbox: Gmail over IMAP through a Vercel serverless function, or Outlook through Microsoft Graph with MSAL sign-in. It finds application emails, classifies each one's stage (applied, interview, offer, rejected), pulls out the role, interview time and salary, and builds a pipeline per company. Adds an interview calendar, side-by-side offer comparison, a STAR story bank and LinkedIn import. Credentials are never stored.

  • React
  • Node
  • Microsoft Graph

LogIngestLLM

A local AI agent that reads Windows Event Log, Linux syslog/journald, app logs and Raspberry Pi/Jetson logs, then summarizes them and flags the security events worth a look. Runs on a Qwen3 4B model I fine-tuned on my own GPU, which raised its importance accuracy from 33% to 87%. No log data leaves the machine.

  • Python
  • LLM
  • Ollama
Code

NetGuard

A network intrusion detection system and SOC console for small networks, written in standard-library Python. It learns what the network normally looks like, catches ARP spoofing, rogue DHCP, port scans and new devices, and groups related alerts into incidents mapped to MITRE ATT&CK, with triage, MTTA/MTTR metrics and pcap forensics. Every detection is proven by attack simulations replayed in CI.

  • Python
  • IDS
  • MITRE ATT&CK
